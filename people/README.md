# People

Person-specific sewing reference: body measurements, fit preferences, and a chronological record of garments made or altered for each wearer.

## Profiles

No person profiles have been committed yet. Add one when source measurements or garment history are supplied, using `people/<person-slug>/`:

- `README.md` — wearer context, fitting preferences, links to measurement and garment records.
- `measurements.md` — dated measurements, units, measurement method/posture, and any known uncertainty. **Never overwrite older values without retaining the date.**
- `garment-log.md` — dated constructions, fittings, repairs, and alterations, each linking to a project under `projects/` when applicable.

A garment project describes the **garment and process**; the person's garment log describes **the wearer's experience and the garment's later lifecycle**. Cross-link rather than duplicate. Multiple people may reference one project. A garment alteration does not always need a full project folder; link it when a dedicated project exists.

**Privacy:** This repository is public. Body measurements and personal logs become publicly visible when committed. Obtain the wearer's permission and avoid identifying/private detail unless explicitly intended for publication.
