# Buttonhole construction and equipment

## Current workflow

The **Brother CS-6000i** is now used **only for buttonholes**; the Juki DDL-8700 handles approximately 99% of general stitching. This is a direct current-state update (2026-11-04), superseding older use of the Brother for muslin and other construction.

## Direct needle and canvas findings — November 4, 2026

- Current successful needle for Brother buttonholes: **Microtex 70/10**. The maker reports that other needles tried caused jams or bent.
- Single-layer heavy canvas buttonholes have been tested.
- Double-layer canvas and alternative thread trials are planned, not yet verified as successful.
- Retain the successful needle as the starting point when evaluating stitch density and thread choices.

## Dress-shirt observations (historical thread exported 2026-11-04)

- Existing automatic buttonhole function and plastic presser-foot assembly work most of the time, but produced **inconsistent results** on cotton broadcloth.
- Thread in discussed trials: **40 wt**; buttons **12–18 ligne (L)**.
- Desired outcome: consistent dense satin stitching, parallel sides, regular length and bartacks, minimal distortion and clean cutting.
- Plastic foot flex was suspected, **not established** as the cause. Feeding, stabilization, and automatic sensing remain possible contributors.

### Options considered, not acquired or implemented

1. Refine Brother stabilization, interfacing, settings and feed support.
2. Vintage Singer/Greist cam-driven mechanical buttonholer, but fit and actual drive/clearance compatibility with any host machine remain unverified.
3. Mechanical attachment for Juki DDL-8700, likewise **unverified**, and cannot be inferred from shank match alone.
4. Dedicated industrial buttonhole machine (e.g. Juki LBH-780) as a possible long-term option, **not owned**.

### Shirt button dimensions discussed

| Button application | Working diameter sizes |
|---|---|
| Sleeve placket | 12–14 L |
| Front placket | 16–18 L |
| Cuff | 16–18 L |

1 ligne = 0.635 mm. Opening-length heuristic: button diameter plus actual thickness, **then test on the button and fabric**; opening length is not necessarily finished buttonhole length including bartacks.

For broadcloth, discussed but not verified on final garments: light interfacing, removable stabilizer where necessary, the proven Microtex 70/10 needle, testing 40 wt satin-stitch thread, supporting garment weight, and chisel/cutting-block opening.

See [Brother CS-6000i](machines/brother-cs-6000i.md) for actual machine use. The quality challenge is still unresolved on available evidence.
