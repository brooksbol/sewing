# Repository working instructions

This repository is a practical sewing workshop memory for multiple independent projects, not an application. No build system, CI, dependency stack, or software architecture is needed.

## Reading order

1. Read this file.
2. Read `README.md` for the project index.
3. Read the relevant `projects/<name>/README.md`.
4. Consult fitting logs, construction notes, and historical experiments only as necessary.

## Editing rules

- Treat each project's README as the **current-state entrypoint**.
- Preserve source-pattern attribution; do not describe experimental modifications as original instructions from the drafting author.
- Separate **confirmed**, **provisional**, **observed**, **hypothesized**, **abandoned**, and **unresolved** statements.
- Prefer dated, append-only fitting observations; refresh the current-state README after a meaningful change.
- Record measurements with units, how and where measured, and seam-allowance assumptions.
- Do not conflate sleeve cap length, cap ease, underarm circumference, or sleeve pitch.
- Do not rewrite history to match the current approach. Clearly label abandoned explorations.
- Do not infer an actual pattern alteration or successful test from conversational recommendations.
- When the maker provides an update, capture it in the relevant project notes; avoid redundant documents.
- Avoid adding automation, generic templates, complex taxonomy, or unrelated project scaffolding without a concrete need.
- Keep personal/sensitive material and copyrighted drafting-book reproductions out of the public repository.
