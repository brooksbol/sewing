# Repository instructions for assistants and Codex

This is a multi-project sewing workshop knowledge base, **not** a software project. Avoid builds, dependencies, CI, or software scaffolding unless specifically requested.

## Bootstrap every thread

1. Read this `AGENTS.md` and root `README.md`.
2. Identify whether the task concerns a **garment project**, a **person**, or a **shared technique/equipment reference**. It may touch more than one.
3. Read the appropriate index: `projects/<garment>/README.md`, `people/README.md` and the relevant wearer profile if present, or `techniques/README.md` and linked technique/machine notes.
4. Follow cross-references for actual source observations; use relevant fitting logs and historical notes when needed.
5. State what is established versus what is proposed; if asked to persist knowledge, update the canonical relevant notes and cross-links.

## Information architecture

- **Projects:** design intent, source patterns, fitting observations, construction experiments, garment-specific settings, decisions, and unresolved work. The project README is the current-state entrypoint.
- **People:** dated body measurements and methods, fitting preferences, and garment lifecycle logs (construction, alterations, repairs). Link each applicable garment to its project rather than copying project details. Preserve older measurements rather than overwriting history.
- **Techniques:** reusable fabric observations, seams/finishes, fitting approaches, machine inventory and settings. Include actual material/sample, date/source, settings and tested outcome. Link to the supporting projects.
- Distinguish *a person-specific fit observation* from *a pattern or technique generalization*.

## Evidence and writing rules

- Separate **observed**, **confirmed**, **proposed**, **hypothesized**, **abandoned**, and **unknown**.
- Prefer dated append-only fitting and garment-log entries; refresh the current-state index after substantive updates.
- Record units, method, measuring position, and stitching-line vs cut-edge assumptions. Do not conflate cap length, cap ease, circumference, or pitch.
- Attribute drafting methods faithfully; do not claim experimental modifications are the pattern author's formula.
- Do not silently rehabilitate abandoned drafts, infer a successful trial, or replace user observations with generic sewing advice.
- Avoid duplicate canonical settings: project notes say what was used, shared references hold reusable settings and inventory.
- Incoming historical context dumps may overlap or conflict: preserve provenance and reconcile against more recent direct observations before updating current state.
- Use succinct links, not broad generic templates or speculative taxonomy.
- No personal/sensitive data, identifying wearer details, or copyrighted drafting-book scans in this **public** repository without explicit permission.
